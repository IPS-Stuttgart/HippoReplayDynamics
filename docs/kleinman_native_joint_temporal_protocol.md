# First native joint temporal-specificity pilot

Frozen after the joint calibration screens passed, before native paired outcomes
are scored. Require independently verified passing calibration before execution.
No drug contrast and no expansion beyond the fixed 48 calibration packets.

Use exactly the selected_packets.csv of the joint calibration, without replacing
poor or zero-information observations. Use all positive-ID raw sorted cells;
reference-only inclusion from R0/R1/R2, never the full-RUN numerical generating
maps. Estimate reference rates as previously, then score R3->R4 and R4->R5 on
identical triple-exposed spatial support. Use the same observed R4 counts for
both comparisons. Recruitment is the already frozen native-ripple/background
log rate enrichment between R4 and R5. Unit identity is session-local.

Primary: prospective-minus-preceding one-step association, averaged equally over
six animal effects, with the already calibrated working 95% t interval.
Keep individual lag effects and all cells/packets visible. Missing conditional
information is missing, not a zero-effect observation. No drug, novelty or
subgroup significance tests; no threshold or event selection changes.

This is an exploratory biological pilot, not independent replication of the
previous native pilot. Explicitly count overlap with its frozen selected anchors
by animal/session/target traversal. A positive contrast would support temporal
asymmetry of association, not that ripples cause plasticity or that a given
ripple contains replay. A null interval does not establish absence/equivalence.
Reference-aligned spatial redistribution is not map reliability or synaptic
change. Ongoing drift controls cover only the tested simulation families.
Future-only calibration detection was 103/128 with Wilson interval about
[0.728,0.864], a marginal point-estimate screen pass, not guaranteed 80% power.

Any proposed subsequent scaling, drug contrast or changed endpoint requires a
separate decision; this pilot cannot resolve missing physical-track identities.
