# Post-Run Summary Review

The source run at commit 09ae1545 froze its protocol before decoding. Its event
readouts remain immutable. Independent reconstruction checked frozen IDs, RUN
errors, real posteriors and conditional simulated paths/counts.

Review found summary/gate defects, corrected without rescoring:

- Restore the protocol's spike-only primary null calibration. Keep joint
  minimum-spike/active-count reweighting explicitly as a sensitivity analysis.
- Check A and B recovery and active-support mismatch separately. Minimum active
  counts and pooled endpoint errors can hide a population-specific weakness.
- Require >=80% calibration coverage and >=40 calibrated rows in each real,
  null-test and injected-conflict session case. These are post-review technical
  denominator guards, not predeclared scientific effect thresholds.
- Require both generator-specific gates in one overall biological-interpretability
  gate. A pass under one generator cannot substitute for failed robustness.

Regression tests exercise zero real calibration coverage, one-generator-only
passes and a poor A decoder hidden by a good B decoder. Corrected summaries and
their provenance are generated by audit_pf_independent_population_content.py
with --refresh-summaries. Producer manifest and event-readout hashes are retained.

The changes do not rescue a biological result: calibration and local RUN
matching remain insufficient. Report the pilot as diagnostic and unresolved.
