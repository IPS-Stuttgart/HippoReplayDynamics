# Fixed-selection evaluation-neuron influence

Freeze before executing new readouts. This is a diagnostic of the surviving
independent-content evidence, not a new replay selection or biological gate.

## Population and source decisions

Both original strict RUN-pass sessions, RAT3_SESS2 and RAT5_SESS2, are required.
Use every POST ripple-positive event/split/repeat that was accepted at full
inference coverage and rejected at half coverage. Never select on held-out
content, posterior confidence, significance or predictive scores. Preserve the
original inference track label for signing independent support. Keep all
detector and inference activity, candidate windows and sequence decisions fixed.

## Intervention

Each original held-out evaluation set contains 12 neurons. Recompute its
sequenceless Poisson and count-conditioned track readouts with every single
evaluation neuron removed in turn. When an omitted neuron is an inference neuron
in another partition, do NOT remove it there: this is an evaluation-readout
influence analysis, not a new global recording-thinning intervention.

Reproduce each full-evaluation readout against the archived rate-matched
identity-null control before proceeding. Reuse its 199 permutations and RUN-only
rate groups. To remove one map/spike identity from a null, delete that vertex
from each permutation cycle. This preserves the other rate-group memberships;
it does not rerank or rematch cells based on POST activity. Keep duplicate null
draws. This deletion of uniform permutations gives uniform permutations on the
remaining members of each original group. Record actual RUN-rate mismatch and
null diversity. Sparse/no-spike cases stay missing rather than zero.

For each physical evaluation neuron, replace only affected event/split readouts;
other splits retain their original full-evaluation readout. Collapse signed
readouts across the same lost split/repeats using an event median, then average
across original events. Report raw log odds, null-centred log-odds excess and
null-standardized z, so changed null scale is not mistaken for changed content.

## Uncertainty and interpretation

Use the existing 60-second occupied-POST-candidate-block design and seed, 2,000
paired bootstrap draws. All omissions share block weights. Report event counts,
affected split/event counts, finite support and paired differences from the
full-evaluation baseline. These are conditional within-session descriptive
intervals, not simultaneous tests across neurons or independent replications.

No minimum over omissions is a calibrated significance statistic. If deleting
one neuron reverses the point estimate or removes its resolution, report that
fragility, without suppressing the other session or choosing a better panel.
If support persists, conclude only that no single evaluation neuron is necessary
for this particular aggregate readout. This cannot prove distributed replay,
recover the true track mixture, resolve shared drift or turn two sessions into
population-level biological confirmation. Future prediction is not rescored.

Archive all omissions, not just the most favourable result. Independently verify
the original-readout match, permutation construction, sampled deleted-cell
likelihood calculations and event aggregation. The focused goal remains whether
sampling hides experience-specific replay content and biases inferred experience;
this diagnostic tests one weakness of the current evidence, not the full claim.
