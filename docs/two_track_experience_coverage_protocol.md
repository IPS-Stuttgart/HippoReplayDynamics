# RUN-only unequal experience coverage: mechanistic intervention

This is a new, frozen sensitivity experiment motivated by the incomplete random
half-sampling composition result. It does not replace that result, alter replay
thresholds, estimate true biological experience fractions, or seek significance
by tuning the decoder.

## Intervention

Use the existing primary RAT3_SESS2 and RAT5_SESS2 banks, all LFP-covered candidate
windows and the existing five disjoint inference/evaluation cell partitions.
Keep detector cells, event windows, RUN maps and the independent evaluation
readouts fixed. Choose subsets using RUN maps only, never PRE/POST spikes,
replay scores, or evaluation-cell results.

For each unit and track compute occupancy-weighted spatial information per spike:
sum_x p_RUN(x) [rate(x)/mean_rate] log2[rate(x)/mean_rate], using valid occupied
RUN bins. Define relative selectivity as track-1 minus track-2 information.
This is an estimated RUN-map measure, not replay selectivity or true neural
information. It can reflect map-estimation and occupancy differences.

Within each inference population, order cells by their mean fitted RUN rate
(occupancy-weighted per track, then equally averaged across tracks). Pair adjacent
cells. In each pair keep the higher relative-selectivity cell for the track-1
arm and the other cell for the track-2 arm. Resolve ties by a fixed identity hash.
If the population is odd, share the final unmatched cell between arms. Both
arms contain ceil(N/2) cells. Pairing approximately matches overall RUN rate;
it is not exact rate matching. Report all pair gaps and aggregate arm rates.

Controls are full inference and five independently seeded complementary random
pair selections at the same half size. These five controls describe sensitivity;
they do not provide a well-resolved permutation p-value.

Keep five active inference cells/five nonempty bins and the original 499 time
and 499 cellwise field-shift nulls, with p < .025 for both per track. Use exactly
the original event/split null seeds. Inference labels never orient evaluation
scores. Evaluation maps/cells are never changed by the intervention.

## Endpoints and uncertainty

Primary: POST ripple-positive events. PRE and covered MUA-only are sensitivities.
Primary endpoint is the difference between selected-set means of the *fixed
evaluation-cell conditional track-2 posterior score*, track-2 arm minus track-1
arm. Expected direction is positive. This score is **not** an estimate of the
true fraction of events generated by track 2.

Required corroborating readout: same contrast using fixed, rate-matched
evaluation-cell identity-null z log odds, oriented toward track 2. These values
are reused from the existing control, not recomputed under the selected cells.
Report classifier track labels separately; a shift in labels without independent
evaluation support is not experience-content confirmation.

Average numerator/denominator contributions across the five splits within each
original event before session aggregation. Each candidate has equal starting
weight; do not treat split copies as independent events. Never select an event
using a pooled evaluation readout or cross-split inference labels. All splitwise
selection/readout pairs use disjoint cells. Empty/unsupported selected sets are
undefined, not zero or a pass.

Use 2,000 paired 60-second time-block bootstrap draws per session/epoch/ripple
stratum, keeping every arm and split of each event together. Require at least
95% finite draws for an interval. Report unique selected events, finite-readout
coverage, candidate count, time-block count, event duration, evaluation spikes
and inference spikes. No animal-population confidence interval is claimed.

A positive mechanistic readout requires both primary sessions to have positive
primary and corroborating contrasts with intervals excluding zero, at least five
unique events providing finite readouts in each targeted arm, and a positive
RUN-selectivity contrast in every split. Failure remains failure, not grounds
for altering subset size, scores or thresholds. All matching diagnostics remain
visible even if the criterion passes.

## Scope

This deliberately changes which experiences the observed population represents
well. It tests whether unequal sampling can alter experience visibility for the
same real candidates, not whether uniform random cell loss caused the observed
experience proportions or how much real replay the unrecorded neurons contain.
It is a mechanistic sensitivity analysis in two sessions, not a population-wide
biological replication. No automatic correction of the original fractions.
